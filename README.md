# moleculer-blog-assets

Images (hero photos and diagrams) for the 2026 Moleculer blog series, hosted here so the
articles can reference them from Medium, dev.to and other syndication targets.

Runnable code for the articles: [moleculerjs/moleculer-examples](https://github.com/moleculerjs/moleculer-examples).

Images are CC BY 4.0; the diagrams are hand-written SVGs, the hero photos are AI-generated.
